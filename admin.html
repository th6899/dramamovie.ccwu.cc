支付安全边界
  • 浏览器只能创建结账请求，不能自行把订单标记为已付款或开通权益。
  • Stripe 仅使用测试模式密钥和测试 Price ID 完成验证；正式密钥不配置在测试项目。
  • 支付宝自动收款仅使用官方沙箱网关和沙箱密钥；验签、金额/币种核对及重复通知测试通过前保持关闭。
  • 微信支付 Native API v3 不具备独立零资金沙箱，当前测试项目保持关闭，不发起真实商户扣款。
  • 人工二维码属于真实资金收款流程；测试项目已锁定开关，只有经单独授权的生产环境才可配置真实商户二维码，并由管理员核实到账后审核。
  • PayPal、Binance Pay、OKX Pay 和链上 USDT 当前不属于已完成的支付接入，不显示为可用通道。

测试环境尚未完成支付端到端验收。所有支付方法保持关闭；请勿将测试环境用于真实收款。
